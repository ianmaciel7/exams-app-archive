# Public evaluation sample

Eleven original questions written during remediation, ten with a minimally relevant target record and one natural absence case. This is an author-curated development sample, not independent human annotation or exhaustive relevance judgments; precision is measured against incomplete labels. Do not tune to this sample and call it holdout. The runner sees only query text and normal public scope/limit; labels are opened only by the separate scorer after capture. CI uploads only public catalog evidence. Historical and agent validation remain blocked/not run.
