## Evidence collection protocol
Search by product, component, state, platform and version. Prefer Pixlpin, Screenrove and The UI Index for discovery, then original sources for feature claims. Distinguish real product observation, promotional image, third-party analysis and inferred behavior. Record original page, media URL, product/version/date, author, state, trigger, before/during/after, timestamps, rights, access status, inspection status and limitations; checksum only for actual authorized files. A static screenshot does not prove motion. Preserve links when redistribution rights are unclear; never bypass paywalls or access controls or publish private data. Deduplicate URLs and evidence IDs; link to patterns, ADRs, components and state transitions. The Visual Evidence Collector is a proposed workflow, not an installed integration. Follow #94, #102 and #105; report blocked or uninspected evidence explicitly.
