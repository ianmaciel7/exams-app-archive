# Laws of UX — application and evidence

Canonical source: https://lawsofux.com/ (30 individual pages verified 2026-11-27). Detailed Portuguese catalog and structured data: https://github.com/ianmaciel7/exams-app-archive/blob/main/docs/references/ui-ux-research-sources/laws-of-ux-2026-11-27.md and https://github.com/ianmaciel7/exams-app-archive/blob/main/docs/references/ui-ux-research-sources/laws-of-ux-2026-11-27.json. Fetch canonical files for definitions, origins, limits, proposed acceptance tests and provenance. Never treat educational heuristics as standards or claim that all cited studies were independently read. Use original sources for stronger causal claims. Visual assets link-only pending rights checks.

- Aesthetic-Usability Effect: perceived usability is not task performance.
- Choice Overload: offer comparison, search and filters; avoid arbitrary choice limits.
- Chunking: organize related information into meaningful groups.
- Cognitive Bias: avoid leading research and manipulative interfaces.
- Cognitive Load: remove unnecessary processing, preserve essential information.
- Doherty Threshold: responsive feedback; 400 ms is historical, not universal SLA. No fabricated progress.
- Fitts's Law: account for target distance and effective width; check WCAG separately.
- Flow: clear goals, suitable challenge, control and feedback; never maximize compulsion.
- Goal-Gradient Effect: show real progress only.
- Hick's Law: choice uncertainty affects reaction time; preserve discoverability.
- Jakob's Law: use familiar interaction conventions, validate local needs.
- Common Region: visual areas can communicate grouping without mandatory borders.
- Proximity: relative distance communicates relationships.
- Prägnanz: reduce perceptual ambiguity without hiding essential content.
- Similarity: make equivalent functions visually consistent; not color alone.
- Uniform Connectedness: represent real relationships, not decorative misleading lines.
- Mental Model: verify users' expectations about objects, tabs, and actions.
- Miller's Law: memory capacity varies; no seven-item UI limit.
- Occam's Razor: simplest sufficient solution, without sacrificing requirements.
- Paradox of the Active User: make exploration reversible and provide contextual help.
- Pareto Principle: prioritize measured frequency and impact, not a fixed ratio.
- Parkinson's Law: remove avoidable work, never impose coercive deadlines.
- Peak-End Rule: make recovery and closure clear; evaluate the entire journey.
- Postel's Law: tolerate legitimate input formats, preserve security and invariants (RFC 9413).
- Selective Attention: prioritize task-relevant information without hiding critical status.
- Serial Position Effect: validate ordering and preserve original exam question order.
- Tesler's Law: handle inherent complexity in the right layer, with user control.
- Von Restorff Effect: reserve distinct emphasis for important actions.
- Working Memory: preserve context and allow recognition over recall.
- Zeigarnik Effect: permit resumption and real pending states; no guilt or compulsive retention.

Select only concepts relevant to the task, identify trade-offs and evidence limits, propose measurable tests, and separate WCAG requirements from psychology. For Exams App preserve selected answer on failure, idempotent retry, truthful progress, original question order, keyboard/touch access and reduced motion. Do not advance sketch/wireframe/prototype stages without evidence. Record primary sources and copyright boundaries.
