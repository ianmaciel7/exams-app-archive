# Discovery metadata integration

Five existing public research catalogs contribute 231 source occurrences: 112 general discoveries, 35 visual discovery leads, and 84 DESIGN.md document metadata records. These are NOT 231 unique URLs or new verified sources. They retain original status, date, URL, record pointer and original/projected hashes. DESIGN.md entries are independent analyses, not brand specifications; the recorded retrieval used a mutable upstream branch, and full source bodies are not retained by this projection. No new live source checks, media collection or rights verification. Exact URL deduplication remains in federated retrieval. Coverage gaps may increase when previously untracked discoveries become visible; this is better accounting, not knowledge regression. Existing production ranking thresholds remain unchanged.
