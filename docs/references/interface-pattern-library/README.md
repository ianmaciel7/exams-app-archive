## Evidence boundary
No claims of a market-share ranking or universal effectiveness. Primary documentation and research catalogs are separated from editorial trends. New platform capabilities require browser/version verification; proposals are not stable APIs. The catalog uses original synthesis and links instead of copying restricted media. Existing archives are preserved. This update does not alter any product.
