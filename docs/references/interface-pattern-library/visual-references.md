# Visual reference gallery (external originals)

These links lead to source-hosted diagrams, demos, video or component galleries. No new screenshot/video bytes are included in this batch. Existing licensed visual assets are in the linked sibling Grok Bot archive. Check licensing before redistribution.

- [Apple HIG — Materials](https://developer.apple.com/design/human-interface-guidelines/materials) — Liquid Glass is a functional control/navigation layer above content.
- [Google Design — Expressive design research](https://design.google/library/expressive-material-design-google-research) — Google reports research on color, shape, size, motion and containment; not universal validation.
- [Android — Material 3 Expressive](https://developer.android.com/design/ui/wear/guides/get-started/design-language) — Shape-morphing controls, adaptive groups and variable font axes.
- [Chrome — What's new in web UI, I/O 2026](https://developer.chrome.com/blog/new-in-web-ui-io26) — Current features and proposals are mixed; check support per feature.
- [Chrome — Modern Web Guidance](https://developer.chrome.com/docs/modern-web-guidance/guides) — Examples for anchored UI, state preservation, native interactions and motion.
- [Chrome — Natural interactions](https://developer.chrome.com/docs/modern-web-guidance/guides/user-experience/natural-interactions) — Press/focus feedback, natural movement and keyboard access.
- [Motion — Examples](https://motion.dev/Examples) — Working examples; check whether individual examples require paid access.
- [Motion — Sheet modal](https://motion.dev/examples/react-sheet-modal) — Spring, drag, swipe dismissal example.
- [Motion Primitives — Docs](https://motion-primitives.com/docs) — Open-source component examples; verify license per imported asset.
- [Motion UI](https://motion.dev/ui/) — Commercial Motion+ gallery; link-only.
- [AI Design Guide — Agentic UX patterns](https://www.aidesign.guide/agentic-ux-patterns) — Catalog reports 39 patterns, 74 screenshots, updated 2026-10-11; not an adoption survey.
- [Google PAIR — Case studies](https://pair.withgoogle.com/guidebook-v2/case-studies) — Product examples of AI supervision and failure recovery.
- [Google — A2UI introduction](https://developers.googleblog.com/introducing-a2ui-an-open-project-for-agent-driven-interfaces/) — Declarative agent-generated UI, rendered using host components.
- [Dashboard Design Patterns](https://dashboarddesignpatterns.github.io/patterns.html) — Composition and interaction including brushing/linking, filtering and details on demand.
- [daisyUI — UI design trends gallery](https://trends.daisyui.com/) — Style exploration; not evidence of user benefit or prevalence.
- [xAI — Designing Grok Bot](https://x.ai/news/designing-grok-bot) — Existing research on agent avatar and state feedback; see sibling archive.
