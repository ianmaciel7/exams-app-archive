# Authenticated archive pin contract

A missing actual index checksum no longer satisfies an expected checksum. A mounted adapter or an expected value alone is not verification. The authenticated caller remains responsible for obtaining the trusted adapter attestation and computing actual digest before supplying it; this is not a new authentication boundary. Explicit repo/ref/commit constraints reject missing or mismatched metadata, including graph/knowledge results before fusion; document and AST inputs also require explicit verified status when requested. Image records remain indexed-not-recovered, not verified pixels. Tests use synthetic fixtures only. Private archive integration must be independently checked on an authorized mounted corpus; no private data enters public CI.
