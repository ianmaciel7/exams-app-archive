## Product observations

- **Action, reusable prompt and checklist:** Task is an action for Codex; Prompt stores a request that a reader can open in chat; Checklist represents checkable items. Do not equate a generated tracker with a scheduled task. Acceptance (not executed): Verify execution confirmation, stored state and manual completion separately. [Official guide](https://learn.chatgpt.com/docs/space/pages).
- **Inherited access and reparenting:** A subpage inherits access from its parent or space. Removing a direct invitation does not remove inherited access. Moving a page requires edit access to both and can alter readers. Acceptance (not executed): Verify direct/inherited access, preview before move and revocation. [Official guide](https://help.openai.com/en/articles/20001549-getting-started-with-space-in-chatgpt).
- **Locked chat file visibility:** Files saved from locked chats are hidden from Space and available only in their originating chat until unlocked; separately linked files retain original access. Acceptance (not executed): Check source access without surfacing protected content in search. [Official guide](https://help.openai.com/en/articles/20001549-getting-started-with-space-in-chatgpt).
- **Typed template versus generic artifact:** Seven named templates correspond to purpose-specific editors. Generic interactive tools can also be created from chat, but are not a separately named eighth template in the guide. Acceptance (not executed): Test creation path, editor identity, availability and export per type. [Official guide](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them).
- **Batched edit requests across Markdown files:** When Claude drafts multiple Markdown files, edit requests can be queued across files; the file list indicates waiting requests, then one message applies the batch. Acceptance (not executed): Test per-file pending requests, submit, errors, partial application and undo. [Official guide](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them).
- **Agent template creates separate copy:** A template shares reusable configuration rather than conversations, computer state or logins. Publishing and updating template, importing a new copy and sharing one live Bot are distinct. Acceptance (not executed): Test copied identity, permission, update and unpublish semantics. [Official guide](https://docs.x.ai/grok-bot/bots).
- **Source labels and grouping:** With five or more sources, automatic labeling may organize them by topic; users may rename, add, remove labels and move sources. Acceptance (not executed): Test threshold, manual relabel, selection and unchanged source identity. [Official guide](https://support.google.com/gemininotebook/answer/16206563?hl=en-CA).
- **View saved generation prompt:** Artifact menu exposes customization prompts for supported types, with viewer shortcut for some study outputs. Acceptance (not executed): Verify original prompt, permissions, reuse and distinction from current output. [Official guide](https://support.google.com/gemininotebook/answer/16206563?hl=en-CA).
- **Export snapshot and citation sheets:** Data table exports use separate data and citation tabs in Sheets; report tables may use individual tabs. Exported changes do not sync back and notebook permissions are not carried over. Acceptance (not executed): Test export, source attribution, new identity, independent permissions and edits. [Official guide](https://support.google.com/gemininotebook/answer/16206563?hl=en-CA).
