## Taxonomy and guidance

Sample App / Example App / Demo App / Reference App are useful labels for a representative application, but not a single industry-standard term. A template is reusable layout/code, a playground enables experimentation, and a high-fidelity prototype simulates a proposed product. These are distinct from component catalogs and UI kits. Recommendation (not an industry mandate): provide a representative application demo alongside foundations, tokens, components and patterns, with meaningful tasks, states, responsive layouts, accessibility and light/dark themes. Test theme changes across representative screens and verify state semantics, contrast, keyboard navigation and responsive behavior. A demo need not have production data or backend.

Evidence limits: official web pages were retrieved; no independent live interaction testing or accessibility audit was performed. Images remain with original sources.
