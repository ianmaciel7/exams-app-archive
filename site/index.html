Exporte o JSON a partir do SQLite autenticado com o plugin Codex, depois selecione o arquivo aqui. O índice importado não é enviado ao GitHub Pages.

Índice histórico ou JSON de grafo
Como gerar o índice no seu computador 
gh auth login
cd plugins/exams-archive
python scripts/archive_query.py sync
python scripts/archive_query.py export-pages --output private.archive-browser.json

Não faça commit nem envie o JSON para um site público. O arquivo pode conter nomes e caminhos históricos privados.
